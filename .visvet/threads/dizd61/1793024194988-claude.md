Done. `compare_box` now does the shared work (members, diff), then hands off once: `file_box` for a file's own box, `type_box` for a type in it. Each says what is special about it: status, content, generated files, links.

The id rule is now a method on the kind: `BoxKind::box_id`.

The file box's content is now decided by its `Language` (new `src/review/language.rs`), not by checking the extension text.
