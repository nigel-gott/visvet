Good question, and the name is misleading. They *can* make a cycle; the code skips the arrow because that arrow is usually wrong.

**Where the arrow comes from:** `compare.rs` has `use crate::review::parse::parse`. visvet reads only the first part, `review`, so it draws compare.rs → `review.rs`. But compare.rs uses nothing in review.rs; it uses `parse.rs`.

**So:** review.rs calls compare.rs (real), and compare.rs "imports" review.rs (false). Together they look like a cycle.

**The honest fix:** resolve the whole path, `crate::review::parse` → `src/review/parse.rs`. Then the false arrow is gone from the map too, not only from the cycle list, and `can_cycle` would only need "is it a code link".
