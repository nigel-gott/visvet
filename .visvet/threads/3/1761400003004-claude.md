Fair challenge. The UI is not the real reason. The real differences:

- **It may not exist on disk.** A deleted file, or the old version of a changed one, only exists in git. So a `FilePath` names a file *in the repo at some version*, not a place on this computer.
- **It is relative.** `src/main.rs` means nothing without knowing which repo. `Cli::root` is the folder that says which repo.

So they are two different things. But the name `FilePath` hides that. My proposal:

1. Rename `FilePath` to `RepoPath`: "a file's path inside the repo".
2. Rename `--root` to `--repo`, and the real folder `main` finds to `repo_root`.

Then a `RepoPath` reads as "a path relative to `repo_root`". Do both?
