Good thought, but a git ref names a **commit** (like `HEAD` or `main`), not a file. Git names a file at a version as `<ref>:<path>`, e.g. `HEAD:src/main.rs`. So even git needs the path half.

visvet already has both halves:

- the ref once, on the review: `compared_against` (a `GitRef`)
- the path on each box: `FilePath`

The new side is your working tree, which has no ref at all, so a `<ref>:<path>` per box wouldn't fit.

So the wheel here is just "a path inside the repo". Rust has no ready type for that, hence the small one. Go with `RepoPath` plus `--repo` / `repo_root`?
