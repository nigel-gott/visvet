They differ on purpose:

- **`FilePath`**: a path inside the repo, as review data, e.g. `src/types/code.rs`. It goes to the UI as JSON.
- **`Cli::root`**: a real folder on this computer (`PathBuf`, Rust's OS path type). It's what you pass with `--root` (default `.`); `main` turns it into the repo's top folder with git.

They never mix: all code below `main` gets the top folder, and every `FilePath` is relative to it.

The confusing part is the name: `cli.root` means "any folder in the repo", then `main` reuses `root` for the real top folder.

Rename the flag to `--repo` and the real one to `repo_root`?
