`Ex` is the parser for one file. It walks the syntax tree once, with a method per kind of thing it meets, for **both** Rust and TypeScript. So 17 methods in one type, doing four jobs:

1. **Walking items**: `item`, `type_item`, `members`, `add_member`, `obj`, `head`
2. **Rust only**: `rust_use`, `rust_impl`
3. **TypeScript only**: `ts_import`, `const_fns`, `heritage`
4. **Finding the names code mentions**, for arrows: `type_names`, `uses`, `unpacked`, `calls`

The two languages are mixed through all of it, which is the main smell.

Proposal: split `parse.rs` into a folder, with `parse/rust.rs` and `parse/ts.rs` for the language-specific parts, `parse/names.rs` for the name finding, and the walker staying in `parse.rs`. `Ex` keeps one small method per job. Adding a language would then mean adding one file.

Do it, or track it as an issue?
