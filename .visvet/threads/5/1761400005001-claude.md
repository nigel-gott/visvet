`#[...]` is a Rust **attribute**: a note on the next item that a tool reads at compile time. Like a Python decorator, but it adds code instead of wrapping it.

Here the tool is **clap**, the command-line parser:

- `#[derive(Parser)]` on `Cli` makes clap write the code that reads the command line into this struct.
- `#[command(subcommand)]` on `cmd` says: this field is the subcommand, the word after `visvet`, like `serve` or `reply`. Each variant of `Cmd` is one subcommand.
- `#[arg(long, global = true, ...)]` on `repo` makes it a `--repo` flag that works with every subcommand.

`cmd` is an `Option`, so plain `visvet` with no subcommand is allowed: `main` then serves.
