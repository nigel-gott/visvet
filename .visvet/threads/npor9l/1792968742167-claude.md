Good catch: `.visvet` was spelled out in six files. Now one module owns it:

- **`src/visvet_dir.rs`** knows the folder's name and layout: `VisvetDir::of(repo)` gives `.threads()`, `.coverage()` and `.hand_off(HandOff::View | HandOff::Show)`, plus its `.gitignore`.
- `holds(path)` says whether a path is inside it (the map uses this to leave it out), and `affects_review(path)` says whether a change there should refresh the map (the watcher uses this).
- The `"view.json"` / `"show.json"` strings became a small **`HandOff`** enum.

No other code names `.visvet` now, apart from two tests. Pushed.
