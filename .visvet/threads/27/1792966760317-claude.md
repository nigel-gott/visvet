Built:

- Threads live in **`.visvet/threads/<id>/`**, **one Markdown file per message**, and are committed with the code. Push and pull share them, and two people replying at once never clash.
- Each file starts with a short header (`box`, `author`, `name`, `kind`, `state`, `at`), then the text, so it reads fine on GitHub or to any AI.
- **New threads get random ids**, like `#k3f9a2`. The 28 existing threads kept their numbers.
- **Messages carry the writer's name** from git `user.name`; hover an avatar to see it.
- The rest of `.visvet/` stays local, and thread files don't show up as boxes on the map.
- When someone else's threads arrive with a pull, the map refreshes by itself.
