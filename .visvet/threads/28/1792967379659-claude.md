Built, and generic: **any Markdown file** is now a box that can carry meaning and arrows.

- **Front matter labels the box.** `kind: issue` or `kind: milestone` replaces the "file" badge (◉ issue, ⚑ milestone), and other values like `status: open` show as tags. A folder takes its `README.md`'s, so a folder can be a milestone.
- **Named code becomes arrows.** Anything in backticks that names a file or box (`ui/src/Graph.tsx::mapView`), and any relative link, draws a dotted **links** arrow. So README, CLAUDE.md and the skill now link to what they mention too.
- **First milestone:** `issues/ui-cleanup/` holds two issues from this thread: split the big UI functions, and break the Debuffs ↔ Views cycle. Each links to the exact functions.

Threads work on issue boxes like any other. Pushed to https://github.com/nigel-gott/visvet/pull/1; reload your tab and zoom into `issues/`.
