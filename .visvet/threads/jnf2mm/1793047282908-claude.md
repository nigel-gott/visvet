A mix. #[derive(...)] itself is built into Rust: it means 'run these derive macros on this type'. Parser, the macro inside it, comes from clap: the 'derive' feature in Cargo.toml (clap = { features = ["derive"] }) adds it, and 'use clap::{Args, Parser, Subcommand}' at the top of cli.rs brings it into scope. #[arg(...)] and #[command(...)] also come from clap. They aren't macros themselves, just settings that clap's Parser derive reads off each field. subcommand and flatten are only words inside #[command(...)], which clap gives a meaning to. Rust's own built-in derives are things like Clone, Debug and Default. I've added this to the Cli step's note.
