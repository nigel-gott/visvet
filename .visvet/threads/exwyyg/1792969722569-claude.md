Fixed. Selecting a box adds its exact arrows, and the layout engine used to re-sort every column to reduce crossings, so the order changed each time.

Now each box starts in **source order** and the layout keeps that order down each column. In `CodeUnit` the fields read `id, name, kind, file, lines, doc, status, …` top to bottom, matching the code, and stay put whichever one you select. I checked five selections in a row.

The cost: a few more arrow crossings in busy views, since order now wins over fewer crossings. Pushed; your tab reloads itself.
