Agreed: `graph.rs` is one CLI command (`visvet graph`) and nothing else uses it. The CLI is spread out today:

- `main.rs`: the argument parsing (`Cli`, `Cmd`), the dispatch, and `visvet view`
- `graph.rs`: `visvet graph`
- `state/threads.rs`: `visvet threads`, `--stop-hook` and `wait`, which only print or wait, so they're CLI too

Proposal: a **`cli.rs` + `cli/`** module holding all of that: `cli/graph.rs`, `cli/threads.rs`, `cli/view.rs`, with `Cli`/`Cmd` in `cli.rs`. `main.rs` shrinks to calling `cli::run()`. Then `src/` reads `cli`, `review`, `server`, `state`, `types`, plus `git` and `main`.
