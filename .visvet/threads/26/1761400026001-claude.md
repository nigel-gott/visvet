Yes: `state.json` holds only the **threads** (and my 📝 notes, which are messages inside them). It's the only state that can't be rebuilt from the code.

The rest of `.visvet/` is short-lived hand-off files, all ignored by git:

- `view.json`: what you have open, so the hook can tell me what "this" is
- `show.json`: where `visvet show` asks your tab to go
- `coverage.lcov`: the last `visvet coverage` run, for the 🧪 debuff

The map itself (boxes, arrows, diffs) is rebuilt from git and the files on every request; nothing about it is saved. Box positions you drag are kept only in your browser.
