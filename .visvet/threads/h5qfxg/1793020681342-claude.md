Agreed, and this one std does have: `dir` is now Rust's `Path::parent` (the folder part of a path) instead of splitting the text on '/'. I kept it as a one-line helper only because `parent` has no answer for an empty path, and the callers want "" (the repo root) then. It now returns a `Path`, which `join` takes directly.
