Partly. Rust's `Path::join` sticks paths together, but it keeps `..` as is: `issues` joined with `../src/a.rs` gives `issues/../src/a.rs`. Resolving `..` in std means `canonicalize`, which reads the disk and fails for files that don't exist, e.g. deleted ones.

So `join` is really "join, then tidy away `.` and `..` as text". I can rewrite it on `PathBuf` (its `components()` does the splitting) so it takes and returns a `RepoPath` instead of strings. Same behaviour, about the same size, typed. Do it?
