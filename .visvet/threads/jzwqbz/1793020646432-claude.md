Done, both:
- Issue: `issues/language-servers.md`, using rust-analyzer and tsserver for exact arrows instead of guessing from names and import text. It names this function as one of the hand-copied rules it would replace.
- `join` is now typed: it takes any path and returns a `RepoPath`, built on Rust's `Path::join` plus `components()`, which splits out the '..' parts; we only drop them. The doc comment says why std leaves '..' in (symlinks) and why text is right for git paths. `RepoPath` can now be printed directly, so callers barely changed.
One behaviour change: a link starting with '/' (`[x](/src/a.rs)`) now means the repo root, which is what it means on GitHub; before, it was glued onto the folder. A new test covers the cases. Tests and clippy pass.
