# Code annotations

- Each note's lines get an amber band in the box's code, and the note sits in a bubble right under them.
- The step's own text is a bubble above its box, with Back, a dot per step, and Next; ← and → step too. No side panel.
- A `###` heading that names a box puts the note in a bubble above that box, or above the nearest box around it that the view draws.
- Notes render the same light Markdown as threads.
