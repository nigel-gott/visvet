# Change coupling

Boxes that always change in the same commits but have no arrow between them: a dependency the code doesn't show and only git history reveals (code-maat's "temporal coupling").

Drawn as a dotted arrow. Probably the most valuable git-derived signal, next to [hotspots](churn-and-hotspots.md).
