# Dimensions

Everything so far shows a project in one dimension: **code**, its folders, files, types and functions. The closest view to how code is written, but not the only useful one. Other dimensions show the same project another way, and you switch between them. The list is in the [dimensions hub](hub-dimensions.md).

- A dimension can be projected into another: in the code dimension, a database shows up as its migration files or ORM classes.
- Each one must come from the project by tools, not be drawn by hand: [extracted, not drawn](extracted-not-drawn.md).
- "Dimension" and "lens" mean the same thing here; naming comes later.
