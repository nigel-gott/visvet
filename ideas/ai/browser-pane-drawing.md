# Drawing in the browser pane

The Claude desktop app's browser pane has draw and annotate buttons that work on any page, visvet included, and send what you marked to the chat. The `visvet view` hook already tells the AI what's on screen, so drawing and map state arrive together.

Free today; worth using for a while before building any drawing into visvet.
