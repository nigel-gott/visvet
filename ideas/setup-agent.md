# Setup agent

An agent works through a project and prepares it for visvet: doc comments, [state machine](state-machine-annotations.md) and [concept](concept-annotations.md) annotations, [tours](tours.md).

- Others on the team may not use visvet, so it repeats as the code changes.
- A skill run in a normal session, on the subscription; not the [runtime model](runtime-model.md) with API pricing.
