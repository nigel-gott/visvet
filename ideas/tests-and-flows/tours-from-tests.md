# Tours from tests

A behaviour test already reads like a [tour](../guided-reading/tours.md): given this state, when this happens, then this.

- Its [traced flow](flows-from-tracing.md) gives the boxes in order; the test's own steps give the text.
- Can't go stale: re-derived on every test run.
