# Koans

"Your turn" points in a [learning tour](learning-tours.md).

- A small editor (Monaco or CodeMirror, both drop into React) with failing code and a failing test. Make it pass to prove you understood. Rustlings is the Rust version of this.
- Runs locally through the visvet server (`cargo test` on a scratch crate); no full IDE.
- Best when the koan uses the project's own code: "here's a broken copy of the function you just read".

Often a conversation is enough instead: [understanding checks](understanding-checks.md).
