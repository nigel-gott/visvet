# Learning tours

A [tour](tours.md) whose goal is to teach the reader the language and libraries. Example: walk visvet's main [flows](../tests-and-flows/flows.md), explaining the Rust, TypeScript and React on the way, and why things were done that way.

Built from:

- [Code span annotations](code-span-annotations.md): click a piece of syntax for an explanation and doc excerpt.
- [Koans](koans.md): small exercises with failing tests.
- [Understanding checks](understanding-checks.md): questions, spot-the-bug, a glossary.
- Questions back: comment threads work anywhere in a tour; learning ones stay [private](private-threads.md).
