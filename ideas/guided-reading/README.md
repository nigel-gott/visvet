# Guided reading

- [Views](views.md): the AI arranges and annotates part of the map to show something.
- [Tours](tours.md): views with steps. Can be [derived from tests](../tests-and-flows/tours-from-tests.md).
- [Learning tours](learning-tours.md): tours that teach the language, using [code span annotations](code-span-annotations.md), [koans](koans.md) and [understanding checks](understanding-checks.md).
- [Notes-first tours](notes-first-tours.md): tours say most things in notes on the code, so the step bubble is short or gone.
- [Margin notes](margin-notes.md): notes beside the code with their code outlined, so the code stays in one piece; needed once tours lean on notes.
- [Option questions](option-questions.md): the AI asks with options, in threads and at tour branches.
- [Private threads](private-threads.md): learning conversations that stay out of git.
- [Fog of war](../box-signals/fog-of-war.md): shows what's left to explore, and suggests the next tour.
