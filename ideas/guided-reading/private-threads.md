# Private threads

The AI decides per thread whether it's committed.

- A thread that settles a design choice is committed, like threads today.
- A learning one (a quiz, a tour check) is about you, not the code, so it stays in `.visvet/` outside git, like [fog of war](../box-signals/fog-of-war.md), and can feed it: a question answered well raises familiarity.
