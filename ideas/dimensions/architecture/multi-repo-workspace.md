# Multi-repo workspace

A system usually spans repos, and a monorepo can't be a requirement.

- **First:** each repo describes its own system and names the others it talks to ([architecture dimension](architecture-dimension.md)).
- **Later:** a visvet workspace outside any one repo that loads several and renders across them.
